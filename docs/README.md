# Baon docs

Baon is an offline-first budget app for students. It tells a student how much is safe to spend today, based on their allowance (baon), what they have now, and the days left until the next allowance.

Live site: https://baon-ph.vercel.app

| Doc | What it covers |
|---|---|
| [Architecture](architecture.md) | How the app is put together: where data lives, how it is locked, how sync works, and what each folder is for |
| [Design system](design-system.md) | Colors, type, spacing, shapes, motion, shared components and the writing rules |
| [Technologies](technologies.md) | Every tool and library Baon uses, and what each one is for |

How to run the app locally is in the [main README](../README.md).
